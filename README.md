## 🔹 About

PiRC Research Lab is a **comprehensive framework** for experimenting with PiRC standards within the **Pi Network**.  
It includes:

- Simulation engines (Monte Carlo, agent-based, distributed consensus)  
- Economic & Sybil attack models  
- Reference token implementation  
- Interactive **web-based dashboard**  
- Automated tests & GitHub Actions CI  

Perfect for researchers, developers, and community contributors.

## 🛠 Features

| Module | Purpose |
|--------|---------|
| `dashboard/` | Interactive web interface with real-time charts |
| `simulation/` | Network & reward distribution simulations |
| `economics/` | Economic stability & reward models |
| `security/` | Sybil & consensus attack simulations |
| `reference_implementation/` | PiRC token reference code |
| `tests/` | Unit & integration tests |
| `docs/` | Documentation & whitepapers |
| `.github/workflows/` | CI / GitHub Actions |
